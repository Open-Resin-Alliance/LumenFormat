# LumenFormat

Specification for the `.lumen` print file format, by the Open Resin Alliance.

- **[lumen-format-spec.md](lumen-format-spec.md)** — the normative specification (v1.0, draft)
- **[LICENSE](LICENSE)** — MIT

Status: **draft**. The format is not frozen; breaking changes are expected until
v1.0 is ratified. Discussion and corrections are welcome as GitHub issues.
